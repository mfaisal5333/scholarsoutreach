# Contributing

Release preparation is in progress. Read PROVENANCE.md before reusing existing material. No project-wide license or contributor license grant is currently established; defer new third-party code and asset submissions until that is resolved. Bug reports, reproducible setup observations and documentation feedback are welcome.

Use Node 22+, run `npm ci` and `npm test`, and make focused changes on a branch. Describe the problem, changed behavior, validation and limitations in your pull request. Preserve human approval before outreach and template/local-storage fallbacks. Include meaningful tests for backend authorization, persistence or request changes. Never commit credentials, CVs, inbox contents, recipient lists or real outreach logs. Use example.com addresses and synthetic fixtures.

Identify the source, author, license and permission for any proposed imported material. Preserve copyright notices. Do not claim unverified usage, performance, contributors or outcomes. Report security issues privately as described in SECURITY.md.
